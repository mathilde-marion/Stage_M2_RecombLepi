# Inférence des taux de recombinaison avec ReLERNN

Ce pipeline permet d’inférer les paysages de recombinaison à partir des données génomiques à l’aide de ReLERNN, en intégrant des informations démographiques lorsque disponibles, comme décrit dans la section 2.4 du matériel et méthodes du rapport de stage.

Un exemple de script est fourni pour une espèce (*Anthocharis cardamines*), illustrant les différentes étapes du pipeline (simulation, entraînement, prédiction et correction des biais).
