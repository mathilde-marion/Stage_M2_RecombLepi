# Conservation de la recombinaison entre espèces

Ce pipeline permet d’identifier des segments génomiques homologues par synténie et d’évaluer la conservation des taux de recombinaison entre espèces, comme décrit dans la section 2.6.2 du matériel et méthodes du rapport de stage.

Le détail des scripts utilisés par ce pipeline sont disponibles dans le sous-dossier "script".
