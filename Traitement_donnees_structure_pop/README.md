# Traitement des données génomiques et inférence démographique

Ce pipeline permet de filtrer les variants (bcftools), de caractériser la structure des populations par ACP (PLINK), d’inférer les histoires démographiques avec SMC++, et de préparer les fichiers nécessaires aux analyses de recombinaison (ReLERNN), comme décrit dans les sections 2.2 et 2.3 du matériel et méthodes du rapport de stage.
